# Пилот Supabase

Эта папка готовит параллельную базу. Действующий Apps Script и Google Sheets автоматически не переключаются.

## Подготовлено

- пользователи, пачки, справочник операций, операции пачки и неизменяемая история;
- роли `admin`, `master`, `sewer`, `accountant`;
- проверки количества и запрет удаления связанных данных;
- Row Level Security;
- клиентам разрешено только чтение, запись должна идти через Edge Functions;
- индексы для поиска и дашборда.

## Подключение

1. Создать отдельный проект Supabase.
2. В SQL Editor применить `migrations/202609230001_initial.sql`.
3. Создать тестовых пользователей в Supabase Auth и заполнить `profiles`.
4. Скопировать `config.example.js` в `config.js`, указать Project URL и publishable key.
5. Никогда не помещать `service_role` key во frontend или GitHub.

## Локальный режим только чтения

1. Создать `supabase/config.js` по образцу `config.example.js` и указать Project URL и браузерный `anon`/publishable key.
2. Открыть приложение с параметром `?backend=supabase`, например:
   `http://localhost:8088/index.html?backend=supabase`.
3. Войти email и паролем тестового пользователя Supabase Auth.

Без параметра `backend=supabase` приложение продолжает использовать Google Apps Script и обычный PIN-вход. В пилотном режиме операции записи намеренно заблокированы.

## Безопасный порядок миграции

1. Импортировать копию `База_Пачек`, `Операции` и пользователей.
2. Сверить количество строк, суммы, статусы и последние 20 пачек.
3. Подключить frontend в режиме только чтения.
4. Добавить Edge Functions для выдачи, приёмки, отмены, редактирования и аннулирования.
5. Временно включить двойную запись: Supabase + Google Sheets.
6. Переключать основную систему только после сверки и резервной копии.

| Google Sheets | Supabase |
|---|---|
| Пользователи | `profiles` + Supabase Auth |
| База_Пачек | `packs` |
| Прайс / справочник операций | `operation_catalog` |
| Операции | `pack_operations` |
| Сканирование / журнал паспортов | `pack_events` |

Google Sheets можно сохранить как отчётную витрину и резервную выгрузку.
